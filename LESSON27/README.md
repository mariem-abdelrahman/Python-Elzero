# تعلم ال Methods الخاصة بال Set الجزء الأول

clear()
بتفضي السيت بتحذف كل حاجه فيها

union()
بتدمج اتنين سيت او اكتر

ممكن نعملها من غير الميثود باستخدام ( | )

add()
بتضيف عنصر للسيت ولازم يكون عنصر واحد فقط

copy()
بننسخ وفي منها نوعين زي ما ذكرنا قبل كده

remove()
بتحذف العنصر اللي محطهولها بين الاقواس
ولو حطينا عنصر مش موجود بيطلع ايرور

discard()
بتشيل العنصر برضو زي ريموف بس لو العنصر مش موجود مبتعملش حاجه مش بتطلع ايرور زي ريموف

pop()

بتشيل عنصر عشوائي من السيت وترجع العنصر اللي اتشال
طبعا هي بتتعامل بالانديكس في العادي بس في السيت معندناش انديكس

update()

بتحدث السيت شبه add() كده بس دي ممكن تحط كذا عنصر
