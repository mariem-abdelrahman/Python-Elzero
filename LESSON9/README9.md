# أحرف ال Escaping وكيفية التعامل معها
\b => back space 
بتشيل الحرف اللي قبلها 
\ ENTER for escape new line 
print ("hello 
i love 
python")
غلططططططططططط
print ("hello \
i love \
python") 
طيب \ لوحده بيعمل اسكيب للحرف اللي بعده 
طيب لو عاوزين نطبعه تبع الجمله نكتبه ازاي 
\\ بنعمله كده 
طيب لو عاوزين نكتب سينجل كوت جوه سينجل كوت او دابل كوت جوه دابل كوت 
" ....\' .... \' "
' .....\" ......\" ' 
او ممكن نكتبهم بالتبادي يعني لو الجمله فيها سينجل نطبعها ب دابل ولو فيها دابل نطبعها ب سينجل 
\n سطر جديد للي بعده 
\r بتاخد الحروف اللي بعديها وبتستبدل اللي قدام بيهم يعني بيتمسحوا خالص وبنحط بدالهم  
print ("12345\rhello")
يطبع hello
\t بيعمل مكانه تاب يعني 4سبيسات
\xو بعدين الهيكس فاليو بندور عليها علي جوجل
