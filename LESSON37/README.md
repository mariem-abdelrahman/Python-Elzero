# شرح تحويل أنواع البيانات Type Conversion

تحويل البيانات في بايثون سهل جدا

ليه بنحول البيانات اصلا ؟

ممكن يكون عندنا نوع بيانات غير قابل للتعديل بنحوله لنوع تاني قابل للتعديل علشان نعدله

str()
ممكن نحول اي رقم صحيح او عشري ل سترينج

tuple()
ممكن نحول ال سترينج والليست و السيت والديكشوناري بس في السيت مبتكونش مترتبه وفي الديكشناري بيرجع ال keys بس

list()
ممكن احول السترينج وال tuple و السيت بس بياخدها بترتيبها اللي هو اصلا مش مرتب و كمان الديكشناري

set()
بنحول السترينج بس بتطلع البيانات ملخبطه وبيحذف الحروف المكرره والحجات اللي من خصائص السيت يعني وكمان بنحول tuple  والليست والديكشناري وبرضو بيكونوا بنفس الشكل

dict()
السترينج مش علي شكل key&value ف مش هينفع

ال tuple مش هينفع بشكله العادي لازم يكون nested ولازم يكون بالشكل المطلوب key&value

الليست نفس الtuple مفيش اختلاف

هنيجي في السيت نعمل نفس صحابها بس مش هتنفع ليه علشان هي unhashable يعني مش بتبقي key&value
