# شرح القاموس Dictionary

بنكتب عناصره جوه {}

العناصر جواه عباره عن key:value
يعني بنكتب العنصر ونديله قيمه او ما يساويه

منقدرش نحط جواها ليست او سيت علشان دي حجات بتتعدل ومش key

مينفعش نحط key مرتين او مينفعش نكرر معلومه مرتين لانه مش بيعترف بالتكرار هو بيحدث باستمرار

مش مرتبه يعني مبنوصلش للعنصر بالانديكس بتاعه لا احنا بنوصل ليه بالkey

get()
بتخلينا نبحث عن العنصر بالkey بتاعه

len()
بتطبع عدد العناصر

عرفت انه ممكن نعمل ديكشناري جوه واحد تاني
وكمان ممكن نعمل اكتر من واحد منفصلين ونجمعهم في واحد في الاخر بال key بتاعهم
