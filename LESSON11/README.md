# كل ما يخص ال Strings

لو مش عاوزه استخدم اسكيب ممكن اكتب بالتبادل بين السينجل والدابل 
طيب لو عاوزه اطبع سترينج في اكتر من سطر من غير اسكيب ممكن اعمله بين 3 دابل او سينجل كوت """السترينج """ ودول ليهم ميه كمان انهم بيعملوا اسكيب لاي كاركتر خاص وبيطبعوه زي ما هو
