# تعلم كيفية أخذ شريحة والتعامل مع ال Index في ال Strings
جميع البيانات في بايثون عباره عن اوبجيكت 
الاوبجيكت هو كائن يحتوي علي العديد من العناصر او عنصر واحد بس 
كل عنصر من العناصر دي بيحتوي علي الانديكس الخاص بيه 
الانديكس ده هو رقم عن طريقه بنقدر نوصل للعنصر 
البايثون بتستخدم زيره بيسد انديكس يعني دايما بنبدا من انديكس زيرو
بنستخدم ال سكوير براكتس علشان ناكسس العناصر 
الانديكسينج والسلايسينج عباره عن نظام بيسمح لينا ندخل علي جزء من العناصر كامله او عنصر واحد بس منها 
## indexing ( access single item ) 
الوصول لقيمه واحده بس من مجموعة القيم 
## slicing ( access multiple sequential items )
ناكسس مجموعة قيم من بدايه لنهايه نحددها
