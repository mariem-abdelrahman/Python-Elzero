# تعلم ال Methods الخاصة بال Set الجزء الثاني

difference()

وممكن نعملها بدون ميثود باستخدام ( - )

difference_update()
بعد ما بتجيب الفرق بتحدث السيت الاصليه بالبيانات الاصليه

وممكن نعملها من غير ميثود ب ( & )

intersection_update()
بتجيب المشترك وتحدث السيت بناء علي النتيجه

symmetric_difference()
