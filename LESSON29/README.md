# تعلم ال Methods الخاصة بال Set الجزء الثالث

issuperset()
بنشوف هل كل العناصر اللي في السيت اللي بين الاقواس موجودين في السيت الكبيره ولا لا

issubset()
بنشوف هل العناصر اللي في الليست الاوريجينال جزء او موجوده في الليست اللي بين الاوقواس ولا لا

isdisjoint()
بنشوف هل منفصلين عن بعض او لا
يعني اي منفصلين يعني مفيش اي عنصر مشترك
يعني لو مفيش اي عنصر مشترك بتطلع true
لو في اي عنصر مشترك بتطلع false
